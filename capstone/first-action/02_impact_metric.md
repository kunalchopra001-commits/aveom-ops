# 02 — Impact metric

*One number, with a unit, and how I measure it before and after.*

---

## The metric

**Minutes to settle one disputed hours line, and the share of disputed lines settled correctly.**

> From **[X] minutes and [Y]% correct** per disputed line today
> to **under [X/3] minutes at [Y+]% correct**.

## How I measure it BEFORE (this weekend, by hand)

1. Sit with [name] for two full runs. Stopwatch on.
2. Count total lines and how many were **disputed** (the three records disagreed).
3. Record minutes spent on disputed lines separately from routine ones.
4. Score correctness against what was actually paid and not challenged by the worker.

## How I measure it AFTER (October)

Identical counting, same person, same task, same scoring. Only the process changes.

## The second number — the one that decides the capstone

**Does the person beat a bare model prompt on the disputed lines?**

| | Person | Bare model |
|---|---|---|
| Disputed lines correct | | |
| Minutes per disputed line | | |

Person wins → pairing has room to help.
Model wins → the task is wrong for this capstone and I change it now, not in October.

---

**Fails the rubric:** "saves time", "improves accuracy", "reduces errors".
**Passes:** a digit, a unit, and a before-and-after method someone else could repeat.
